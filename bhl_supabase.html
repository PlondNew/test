Quick Edit Guide
To update standings, stats, rosters, or any data on this site:
1. Open the bhl_s28.html file in a text editor (Notepad, VS Code, etc.)
2. Use Ctrl+F to search for the data you want to change (e.g. a player name or "0" in a standings row)
3. Edit the value directly in the HTML
4. Save the file and re-upload it to GitHub Pages

Or simply upload your updated spreadsheet to Claude and ask for a rebuild!
How to Update
Step-by-step guide to hosting and updating this website
🚀 Step 1: Host on GitHub Pages (Free)
1

Create a free GitHub account

Go to github.com and sign up for a free account if you don't have one already.

2

Create a new repository

Click the green "New" button. Name it something like bhl-season28. Make sure it is set to Public. Check "Add a README file". Click "Create repository".

3

Upload the HTML file

Click "Add file" → "Upload files". Drag and drop the bhl_s28.html file you downloaded from Claude. Then rename it to index.html (GitHub Pages requires this name). Click "Commit changes".

4

Enable GitHub Pages

Go to your repository's Settings → scroll down to Pages → under "Source" select Deploy from a branch → choose main branch → click Save.

Your site will be live at: https://YOUR-USERNAME.github.io/bhl-season28/
5

Share the link!

GitHub Pages usually goes live within 1–2 minutes. Share your URL with the league. It's free, permanent, and accessible from any device.

✏️ Step 2: Updating the Site
A

Option A — Let Claude rebuild it (easiest)

Come back to Claude at any time, upload your updated spreadsheet file, and say "Rebuild the BHL website with these new stats." Claude will generate a fresh HTML file with all the new data. Then just re-upload it to GitHub as shown in Step 3 above.

B

Option B — Edit the HTML directly (fastest for small changes)

Download index.html from GitHub. Open it in any text editor (Notepad, VS Code, TextEdit). Use Ctrl+F (Find) to locate the data you want to change — search for a player name, a "0" in a stats row, or any text on the page. Edit the value, save, and re-upload to GitHub.

Example: To update Youppi's goals from 0 to 3, search for "Youppi" and change the <td class="td-num">0</td> after G to <td class="td-num">3</td>
🔄 Step 3: Re-uploading to GitHub
1

Go to your repository

Log into GitHub and open your bhl-season28 repository.

2

Click on index.html

Click the index.html file in the file list.

3

Click the pencil icon (Edit) or upload new version

Either click the pencil ✏️ icon to edit directly in the browser, OR click the three-dot menu → "Delete file", then re-upload the new version via "Add file" → "Upload files".

4

Commit changes

Click "Commit changes". GitHub Pages will automatically update your live site within about 60 seconds.

💡 Tips
• Passcodes — Share each team's passcode privately with their GM. Change them anytime by editing the TEAM_PASSCODES object in the HTML's <script> section.
• Moderator passcode — Currently MOD-YOUPPI28. Change it in the MOD_PASS variable.
• Stats updates — After each game night, come to Claude with updated scores and it can refresh the whole file.
• Bids are session-only — The bid submission system stores data in the browser session only. Any submitted bids are cleared when the page reloads. For a permanent bid log, use Claude to add new bids directly to the approved offers table in the HTML.
• Custom domain — GitHub Pages supports custom domains (e.g. bhl-s28.com) for free if you own one.
